# B35-B38 Quality Ops Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]` / `- [x]`) syntax for tracking.

**Goal:** Add the next stability layer for the watch decision system: queue/cron observability, stage-gap guarding, stricter public quality gating, and cleaner memory-loop learning context.

**Architecture:** Keep the existing public board layout untouched and work in the data/quality layer only. Queue and run ledgers are summarized by a small pure library plus a protected diagnostics route; model quality and memory-loop changes stay inside existing pipeline helpers and tests.

**Tech Stack:** Next.js 14 App Router, TypeScript, Vitest, Vercel KV-compatible ledgers, Vercel Queue callback path.
