④ 流程 6 步板块动效

每步是一个 流程板块（标号 + 标题 + 角色 + 代理卡片组 + 输入/流程/输出 meta 行），动效定义板块如何进场、内部 agent 怎么激活、说话三点何时出现。说话三点已改为 三点整体同步慢呼吸 (1.6s)，burst 状态加速到 0.8s，不再 stagger。
