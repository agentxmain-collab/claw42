说话三点

位置规则

  • 主位 (A · 头顶)：focused agent + 任何主动说话的 agent · 气泡尾部指向头部
  • 副位 (B · 右侧)：当主位被占用 / 多 agent 同时说话时降级到侧位
  • 层级：z-index 50 (高于 focus frame)
  • 距离：与 head 边缘 12px gap

气泡视觉

  • 背景：rgba(13,8,32,0.92)
  • 描边：accent op 0.65 · 1px
  • 圆角：18 18 18 6 (主位) / 18 18 6 18 (副位)
  • 三点：6×6 圆 · accent fill · glow 6px

表情切换 · idle → talking

EYE BLINK 4.6s → TALK SCAN 0.42s
IDLE · 4.6s blink
TALKING · 0.42s 高频

idle 状态

  • 眼：4.6s blink cycle (94-96% squint)
  • 身体：5.4s float bob -6px
  • 外发光：accent 30px · 静态

talking 状态（触发：hover / 收到信号）

  • 眼：高频 squint loop · 0.42s · 18 ↔ 6 px
  • 屏内：accent 扫描带从上向下 · 1.6s linear loop
  • head 描边：glow pulse 1.6s · op 0.55 ↔ 1.0
  • 外圈：双层呼吸环 ringExpand 2s · stagger 0.7s

切换时序

idle → talking0.2s 过渡 (eye + scan in)
talking 最小持续1.6s (一轮 scan)
talking → idle0.3s 过渡 · scan fade out
