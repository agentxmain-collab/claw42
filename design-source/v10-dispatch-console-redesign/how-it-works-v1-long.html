How it works/ workflow manual/ last updated · 2026.05

一笔交易决策，
不是一个 AI 拍脑袋。
是 11 个角色 · 6 阶段
协同产出。

claw42 把"加密交易决策"拆成一条结构化产线：4 名分析师并行采集情报、2 名研究员多轮辩论、交易员综合下单方案、3 派系风控审查、组合经理终审，所有结论持续回灌到下一次决策。

为什么比单模型更可信。 每一步都有专人、每一个分歧都被记录、每一次成败都被复盘——你看到的不是一个 "AI 给的答案"，而是一份可追溯到角色、回合和论据的决策档案。

信息收集 · 4 名分析师并行采集

02/ 06 · DEBATE

多空辩论 · 两名研究员结构化对抗

看多与看空研究员各拿到完整简报，按回合提出立论、反驳、再立论。直到一方无法再补强论据，或回合上限。我们要的不是"中庸"，是被压力测试过的论据。

agents2 个 · 多轮 debate
输入4 份分析师简报
回合3–5 轮

03/ 06 · TRADER

交易方案 · 交易员综合下单意图

交易员接管全部前置产出——4 份简报 + 多空辩论纪要——拍出一份带方向、时机、仓位、止损的可执行 trade proposal。不评判好坏，只回答"如果要做，怎么做"。

04/ 06 · RISK

风险审查 · 三派系再辩论

交易员的方案进入风控环节。三种风险哲学各派一个角色，从波动性、流动性、相关性三角度交叉审查方案，在彼此之间辩论后给出调整建议（仓位收/扩、止损位、入场节奏）。

agents3 个 · 多轮 debate
输入trade proposal v1
输出proposal v2 · 调整后

激进派

aggressive · push for upside

认为机会窗口短、不出手就是错过。倾向于加大仓位、放宽止损、抢更前的入场点。

  • 当前仓位是不是不够吃下完整行情？
  • 止损位是不是给得太紧、容易扫损？
  • 是否可以分批加仓抢突破？

中立派

neutral · balance & cross-check

不站立场，专挑两边逻辑的漏洞和未充分量化的相关性。强调与组合现有头寸的相互作用。

  • 与已有头寸的相关性是否被低估？
  • 波动率假设的置信区间多大？
  • 有没有信息源被忽略？

保守派

conservative · preserve capital

把"不亏"放在"赚"前面。追问流动性、滑点、极端行情下的回撤上限，倾向于砍仓位、提高止损质量。

  • 极端波动下最坏 drawdown 多少？
  • 这个标的的流动性能不能让我们干净出场？
  • 仓位是否应该砍到一半？
三派在辩论室中互相质询，不投票、不平均——由"最强论据胜出"原则得到一份带具体修订项的 proposal v2。

05/ 06 · PM

最终决策 · 投资组合经理终审

组合经理拿到 proposal v2 与所有上游档案，从全组合的角度给出二元裁决：批准 → 进执行队列；拒绝 → 整条决策档案直接落盘到复盘库，等下一次同标的运行时被回看。

agents1 个 · 单点终审
输入proposal v2 + 全档案
输出approve / reject
portfolio manager · A11

组合经理

唯一对最终交易负责的角色。它不重新做分析，也不再跟谁辩论——只回答："这笔交易，放进当前这个组合，是否值得做。" 它能看见所有 10 个下游 agent 的轨迹与论据。

decision
✓ approve
✕ reject
是否与组合现有风险预算冲突CHECK

多空辩论的最强反方论据是否被回应CHECK

06/ 06 · MEMORY

复盘沉淀 · 持久化机制，不是独立 agent

每一笔决策——无论是否被执行、是否盈利——都连同所有论据、辩论纪要、修订日志一起落盘。后续运行时，相关角色会被自动注入历史经验。系统跨次累积教训，越跑越懂。

typepersistence layer
scope所有 11 个 agent
trigger每次决策结束
memory loop · cross-run

越跑越懂的关键在这里

很多"AI 交易 bot"在每笔决策之间是失忆的：跑完一次就忘。claw42 把决策档案视为最重要的资产——它是下一次决策的先验。当组合经理判断"这个仓位看起来跟去年 ETH 那一笔很像"，它真的能看见去年那笔。

  • M.01 每次决策落盘存档——分析简报、辩论纪要、风控修订、终审判决、执行结果一起进档。
  • M.02 同标的经验回灌——下次同标的运行时，分析师与研究员会先读历史决策与其后续走势。
  • M.03 跨标的教训注入组合经理——结构相似的失败模式（如解锁日前抄底、流动性陷阱）会被识别并预警。
  • M.04 角色级反思——每个 agent 在决策结束后留一段"我哪里错了/对了"，下次输入给同岗位 agent。
